# Диаграммы сравнения медицинского оборудования (LBC)

Готовые диаграммы для просмотра в AutoTrace Lab. Формат совместим с кнопкой
**«Загрузить диаграмму»** в шапке приложения.

## Файлы

- **`lbc-equipment-comparison.json`** — общая схема сравнения всех 12 платформ
  жидкостной цитологии: общий вход образца → параллельные линии оборудования →
  внешняя Pap-окраска (где требуется) → финальный QC. Вложенные подсхемы
  (по одной на платформу) открываются двойным кликом по блоку устройства.
- **`<platform-id>.json`** — отдельный плоский поток технологических этапов
  для каждого аппарата.

## Как загрузить

1. Запустите приложение (`npm run dev`).
2. Нажмите **«Загрузить диаграмму»** в шапке.
3. В проводнике выберите нужный `.json` из этой папки.

## Перегенерация

Файлы генерируются из данных `src/data/lbcWorkflowData.ts`:

```bash
npm run export:diagrams
```

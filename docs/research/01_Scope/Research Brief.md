# 📋 Research Brief: AutoTrace SDK Embeddability & Architecture

## 1. Цель исследования
Исследовать, структурировать и доказать архитектурную пригодность библиотеки `@autotrace/sdk` для бесшовного встраивания в сторонние программные системы любого типа (Web UI, Node.js backend, Go backend, Web Workers, Electron/Tauri десктоп).

## 2. Главный вопрос
*Каким требованиям должен отвечать современный движок ортогональной маршрутизации и оптимизации схем, чтобы обеспечивать 0 ms задержки накладных расходов, 0 внешних зависимостей, абсолютную математическую детерминированность (0 наложений, 90° выходы портов) и изоморфную переносимость между средами выполнения?*

## 3. Для кого проводится исследование
* **Разработчики редакторов диаграмм и схем** (React Flow, Svelte Flow, Vue Flow, Canvas, Konva, SVG-редакторы).
* **Инженеры EDA/CAD и схемотехнических пакетов** (электронные схемы, гидравлические/пневматические контуры, промышленные P&ID графы).
* **Архитекторы backend-сервисов** (генерация топологий отчетов, серверный экспорт в SVG/PDF, CI/CD графы).

## 4. Объекты исследования
* `@autotrace/sdk` (TypeScript Core + Wasm Bridge)
* `autotraceLab/go_engine` (Native Go Routing Core)
* Сравнительные референсы: `ELK.js` (Eclipse Layout Kernel), `Dagre`, `Cytoscape.js`, `libavoid` (Adaptagrams).

## 5. Включено в scope (In-Scope)
* Анализ чистоты зависимостей (Zero-deps packaging, CJS/ESM/TypeScript types).
* Анализ инвариантов геометрии: 90° нормали к граням, 0 px коллинеарных перекрытий, прыжковые мостики, G1-скругления.
* Архитектура дифференциального пересчета (`ScenePatch`, ревизионный контроль).
* Многокритериальный оптимизатор размещения на основе проекционного градиентного спуска (NLP Optimizer).

## 6. Исключено из scope (Out-of-Scope)
* Специфичный UI рендеринг реактовских кнопок и меню (рассматривается только генерация чистых SVG Path и геометрических векторов).
* Облачные сервисы авторизации.

## 7. Критерии успеха (Success Criteria)
1. Полное отсутствие внешних runtime-зависимостей в `@autotrace/sdk`.
2. Наличие синхронного API `routeOrthogonal()` без Promise-оверхеда для критичных к FPS циклов рендеринга.
3. 100% прохождение тестов по 16 комбинациям граней портов и 0 px коллинеарным наложениям.
4. Исследовательская база знаний в формате Obsidian, готовая к навигации и проверке фактов.

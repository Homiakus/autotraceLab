# Batch Monte Carlo Risk

Этот режим объединяет два слоя AutoTrace:

- синхронизированные batch/rack/rotor cycles;
- Monte Carlo анализ неопределённости времени.

## Запуск

```text
http://localhost:3000/?view=process-batch-risk
```

или:

```text
http://localhost:3000/#process-batch-risk
```

Режим читает:

1. последнюю Resource Simulation модель;
2. последнюю Batch Simulation policy.

## Принцип

В каждой Monte Carlo итерации сначала генерируются новые длительности блоков в пределах заданного uncertainty, после чего **заново запускается полный batch scheduler**.

Поэтому пересчитываются:

- ready time образцов;
- момент набора minimum batch;
- timeout неполной партии;
- фактический состав каждого batch cycle;
- очередь оборудования;
- makespan;
- throughput;
- batch fill;
- число partial cycles.

Это отличается от простого умножения готового makespan на случайный коэффициент.

## Uncertainty

В UI для каждого блока задаётся `±p%` вокруг базового времени.

Используется triangular distribution:

```text
min  = base × (1 - p)
mode = base
max  = base × (1 + p)
```

`0%` означает детерминированный этап.

## Метрики

Рассчитываются P50/P90/P95/P99 для:

- makespan;
- average cycle time;
- throughput;
- average wait;
- average batch fill;
- числа partial batch cycles;
- общего числа batch cycles.

При заданном SLA по makespan рассчитывается вероятность выполнения SLA.

## Воспроизводимость

Monte Carlo использует детерминированный seed. При одинаковой модели, batch policy, uncertainty и seed результат воспроизводится.

## Интерпретация

Особенно полезно смотреть одновременно:

- `Makespan P95` — консервативную оценку времени партии;
- `Batch fill P50/P95` — устойчивость заполнения корзин;
- `Partial cycles P95` — риск лишних неполных запусков;
- `Throughput P50` — типичную производительность;
- `SLA confidence` — вероятность выполнить заданный предел.

## Ограничение текущей модели

Текущая версия моделирует **неопределённость параметра длительности блока между сценариями**. Внутри одной Monte Carlo итерации одинаковый тип блока использует одно sampled-время для всех образцов этого сценария.

То есть это прежде всего uncertainty/sensitivity модели, а не полная микроскопическая модель независимой случайной длительности каждой отдельной операции каждого образца.

Следующий уровень может добавить per-task stochasticity, случайные arrivals, MTBF/MTTR, rework и QC reject.

## LBC

Для LBC этот анализ предназначен для исследования организационной устойчивости потока и batch-политик. Он не должен использоваться для самостоятельного изменения валидированных параметров медицинского изделия, реагентных стадий или клинического протокола производителя.

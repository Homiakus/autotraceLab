# LabTrace: прогрессивные схемы и встраиваемый UI

`LabTrace` строится как UI-слой над headless-ядром `AutoTrace`. Ядро отвечает за граф, layout и трассировку, а `@autotrace/sdk/labtrace-ui` даёт готовую редакторскую поверхность для встраивания.

## Прогрессивная схема

Контракт `LabTraceProgressiveScene` описывает не один плоский canvas, а дерево уровней:

- `overview`: сравнение систем или оборудования;
- `system`: состав выбранной системы;
- `process`: технологические этапы внутри блока;
- `operation`: подробная операция, порт или ресурс.

Узел верхнего уровня может владеть дочерней сценой. Поэтому пользователь сначала видит читаемую архитектуру, затем двойным кликом раскрывает только нужный прибор или процесс. Доменные адаптеры поставляют данные, но не форкают редактор.

## Встроенные UI-зоны

`LabTraceWorkbench` владеет стабильными областями с атрибутом `data-labtrace-zone`:

- `header`: идентичность встроенного редактора и глобальные действия;
- `sidebar`: каталог доменных объектов, фильтры и шаблоны;
- `toolbar`: контекстные действия текущего уровня;
- `canvas`: блоки, порты, связи, трассировка и встроенный инспектор;
- `overlays`: модальные окна, уведомления и host-specific панели.

Хост заполняет зоны React-содержимым и управляет предметными данными. LabTrace сохраняет одинаковую геометрию, поведение canvas и UX переходов между уровнями.

```tsx
import {
  LabTraceWorkbench,
  DiagramCanvas,
} from '@autotrace/sdk/labtrace-ui';
import '@autotrace/sdk/labtrace-ui/style.css';

<LabTraceWorkbench
  brand={<YourBrand />}
  sidebar={<YourDomainCatalog />}
  toolbar={<YourSceneActions />}
  headerActions={<YourGlobalActions />}
>
  <DiagramCanvas {...sceneProps} />
</LabTraceWorkbench>
```

LBC comparison является первым адаптером этого контракта. Его обзорная сцена показывает общий вход, сравниваемые приборы, внешние модули, QC и LIS. Каждый прибор раскрывается во внутреннюю сцену из восьми технологических этапов.

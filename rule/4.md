# Rule 4 — Semantic Layout, Adaptive Ports and Perceptual Composition Invariants

These rules are non-negotiable implementation invariants for semantic layout work.

1. **Never trade validity for aesthetics.** Tier-0 validity is feasibility, not a weighted term.
2. **Never trade a crossing for a better golden-ratio/thirds/balance score** unless a versioned profile explicitly permits a bounded Tier-1 regression; default profiles do not.
3. **Golden ratio is not a law.** It is a weak optional composition prior only.
4. **Do not force golden rectangles.** Node size is driven by content, labels, ports, shape and domain constraints first.
5. **Explicit semantics beat topology heuristics.** Source/sink/category/hierarchy/lane metadata outrank degree inference.
6. **Do not assume one main path.** Narrative backbone may contain multiple co-primary paths or a critical subgraph.
7. **Do not place nodes by rectangle packing as the quality objective.** Packing is a fallback/economy concern.
8. **Fixed means fixed.** Pinned nodes and fixed ports never move during layout, cleanup, composition or routing.
9. **Allowed vs preferred is explicit.** `allowedSides` is hard; `preferredSide` is a preference.
10. **Do not choose adaptive ports independently when ordering matters.** Side/order/routing interactions must be evaluated jointly within a bounded planner.
11. **Routers do not secretly move ports.** Port side/anchor selection belongs to the port planner; routers consume resolved endpoints.
12. **Port capacity is validity.** Never overload a single/bounded port to improve geometry.
13. **Preserve port order/group constraints.** Stable ID is only the final tie-break.
14. **Labels are geometry.** Title/port/edge/group/lane label footprints participate in layout where they affect collisions or size.
15. **Core never reads DOM/SVG pixels.** Text measurement and visual geometry enter through renderer-neutral contracts.
16. **Compound graphs are first-class.** Never flatten nested groups merely to simplify the solver.
17. **Swimlanes are semantic layout structure.** They are not decorative background rectangles.
18. **Feedback is intentional geometry.** SCC/feedback edges should use explicit corridors/policies instead of being treated as ordinary backward-flow failures.
19. **Self-loops are dedicated cases.** Do not feed self-loops through ordinary inter-node side selection.
20. **Shared trunks/buses require semantic permission.** Similar geometry alone is not permission to merge paths visually.
21. **Symmetry requires semantic equivalence.** Do not make critical and exception branches look equivalent only for visual balance.
22. **Negative space is bounded.** Importance-driven whitespace must saturate and respect `MaxCompositionExpansion`.
23. **Composition frame is explicit.** Infinite canvas, viewport, slide and print page are different optimization contexts.
24. **Avoid circular golden-guide optimization.** Freeze a provisional semantic frame before applying thirds/golden guide refinement.
25. **Mental map is a first-class objective.** Small edits should produce local changes when feasible.
26. **Use hysteresis for adaptive ports/branch sides.** Tiny wire-length gains do not justify visible flapping.
27. **Joint refinement is bounded.** No unbounded global combinatorial search in canonical interactive mode.
28. **Determinism is mandatory.** No visible choice may depend on Go map iteration or unseeded randomness.
29. **Use quality vectors, not one magic score.** Readability, stability and composition remain inspectable.
30. **Raw and normalized metrics both matter.** Do not compare different graph scales using only absolute counts.
31. **Accessibility is semantic redundancy.** Color is never the only carrier of connection/status meaning.
32. **Explain significant decisions.** Debug/benchmark output should say why a node/port/branch moved or stayed.
33. **Fallbacks are validated.** No failed semantic layout may publish unchecked geometry.
34. **Existing layouts remain reference/fallback until the new default passes production gates.**
35. **Art serves comprehension.** Hierarchy, continuity, proximity and clarity outrank decoration and compactness.
